# Changelog

- Расходы: дата и сумма вернулись к прежнему начертанию, жирнее остались только категории и описание; сумма чуть крупнее (36 px)

## v2.0.2 — 2026-10-04

- Отчёты: топ-3 категорий и последние записи крупнее, сумма отделена от названия категории
- Расходы: шрифт на ступень жирнее (Light → Regular)
- Кэш service worker — `myfinance-v13`

## v2.0.1 — 2026-10-04

- Поле суммы больше не вызывает полосу автозаполнения Chrome (ключ / карта / адрес) над клавиатурой
- Больше воздуха, как в Depoza: шрифт списков и полей мельче, разделители тоньше и бледнее, с отступами по краям
- Новые иконки нижней панели (Отчёты, Расходы, История)
- Кэш service worker — `myfinance-v12`

## v2.0.0 — 2026-09-26

### Форк Depoza: экраны работают как в оригинале
- Отчёты — сохранённые фильтры: только сумма / 5 записей / топ-3 категории; 📌 закрепляет один отчёт с графиком; ⋮ — редактировать/удалить; экран «Новый отчёт»
- История: итог, период «Начало / Окончание», вид Категории⇄Записи, экран «Фильтр», тап по категории с плашкой «СБРОСИТЬ», «Назад» возвращает к категориям, свайп по периодам
- Редактирование записи (дата, сумма, категория, описание), экран «Категории» (переименование, удаление)
- Время траты у записей; категории при вводе — по частоте за месяц
- Исправлено относительно Depoza: «последние N дней» включают сегодня, период с одной границей, поиск по кириллице без учёта регистра
- CSV: добавлен столбец «Время»; отчёты попадают в бэкап и Dropbox
- Номер версии виден в меню ⋮ Истории; версии отмечены тегами в git
- Кэш service worker — `myfinance-v11`

## v1.2.0 — 2026-09-26

### Автокопия и перенос данных
- Автоматическая копия в Dropbox после каждого изменения (OAuth PKCE прямо из браузера, без сервера) + ежедневные снимки в `history/`
- При подключении Dropbox: пустое приложение восстанавливается из копии, непустое — объединяется с ней без дублей
- Меню «Данные» в Истории: бэкап в JSON, импорт из файла (свой бэкап или экспорт из Depoza)
- Первый импорт в пустое приложение заменяет стандартные категории категориями из файла

### Дизайн
- Палитра Depoza вместо Espresso: оранжевый `#E66E02`, светлый фон, белые карточки; иконки перекрашены
- Мягкая типографика как в Depoza: шрифт Roboto (Light на экране ввода), серые тона текста вместо чёрного, разделители в списке категорий
- Кэш service worker — `myfinance-v9`

## v1.1.0 — 2026-07-29

### Подготовка к сборке APK
- Иконки переведены с SVG на PNG (192, 512, 512 maskable) — требование для установки PWA и сборки APK
- `manifest.json`: иконки purpose разделены на `any` и `maskable` (вместо совмещённого)
- Кэш service worker обновлён до `myfinance-v7`

## v1.0.0 — 2026-03-15

### Первый релиз
- PWA-приложение для учёта расходов (аналог Depoza)
- Три экрана: Расходы, Отчёты, История
- Добавление расходов с категорией, суммой, заметкой и датой
- 10 универсальных категорий по умолчанию + возможность добавлять и удалять свои
- Отчёты: карточки Сегодня, Вчера, Неделя, Месяц (+ Год по запросу)
- История с поиском и экспортом в CSV (Excel-совместимый)
- Офлайн-режим через Service Worker
- Палитра Espresso (Double Shot / Cream)
