# My Finance

PWA-приложение для личного учёта расходов — минималистичный аналог Depoza. Работает офлайн, все данные хранятся локально на устройстве.

🔗 **Сайт:** https://estershadow.github.io/My-finance/

## Возможности

### Расходы
Быстрое добавление трат: дата (сегодня/вчера/выбор из календаря), сумма крупным шрифтом, поиск и выбор категории из списка (с возможностью добавить свою на лету), необязательная заметка.

### Отчёты
Карточки по периодам — Сегодня, Вчера, Неделя, Месяц (по запросу можно добавить Год). Тап по карточке открывает полную разбивку по категориям за период.

### История
Все записи, сгруппированные по дням, с поиском по категории и заметке и экспортом в CSV (Excel-совместимый, с датой, категорией, суммой и заметкой).

### Резервная копия
- **Автоматически в Dropbox** — после каждого изменения, как в Depoza. Копия лежит в папке приложения в Dropbox (`myfinance_backup.json` + снимок на каждый день в `history/`). При подключении на новом телефоне данные восстанавливаются сами.
- **Вручную** — История → ⋮ → «Сохранить бэкап (JSON)» / «Загрузить из файла». Импорт понимает и экспорт из Depoza.

### Категории по умолчанию
Продукты питания, Жильё и ЖКХ, Транспорт, Кафе и рестораны, Здоровье, Одежда и обувь, Развлечения, Красота и уход, Связь, Подарки — можно добавлять свои и удалять любые долгим нажатием. При первом импорте данных в пустое приложение стандартные категории заменяются категориями из файла.

## Технологии

Чистый HTML/CSS/JS без фреймворков. Хранение данных — `localStorage`. Офлайн-режим и установка на устройство — через Service Worker (`sw.js`) и Web App Manifest (`manifest.json`).

## Настройка Dropbox (для своей копии приложения)

1. [dropbox.com/developers/apps](https://www.dropbox.com/developers/apps) → Create app → Scoped access → App folder.
2. Permissions: `files.content.write`, `files.content.read`.
3. Settings → OAuth 2 → Redirect URIs: адрес сайта, например `https://estershadow.github.io/My-finance/`.
4. App key вставить в `DROPBOX_APP_KEY` в `js/cloud.js`. Ключ не секретный: вход работает только со страниц из списка Redirect URIs, секрет приложения не используется (PKCE).

## Установка

**Как PWA:** откройте [сайт](https://estershadow.github.io/My-finance/) в браузере и выберите «Добавить на главный экран» — приложение установится и будет работать офлайн.

**Как APK:** приложение также собрано под Android через [PWABuilder](https://www.pwabuilder.com) (обёртка Trusted Web Activity).
