# Проект: PWA трекер расходов (аналог Depoza)

## Цель
PWA-приложение для личного учёта расходов. Аналог Depoza — минималистичный интерфейс.

## Стек
- Чистый HTML + CSS + JS (без фреймворков)
- PWA: `manifest.json` + Service Worker (`sw.js`) — офлайн-режим
- Хранение данных: `localStorage`

## Структура файлов
```
index.html
manifest.json
sw.js
CHANGELOG.md
.gitignore
css/style.css
js/app.js       — навигация, UI, обработчики событий
js/storage.js   — CRUD операции с localStorage
js/reports.js   — расчёт по периодам, formatAmount, formatAmountHTML
js/export.js    — экспорт в CSV (Excel-совместимый, UTF-8 BOM)
icons/
  icon-192.svg
  icon-512.svg
```

## Экраны (3 вкладки, нижняя навигация)

### 1. Расходы (добавление записи)
- Дата: «сегодня» / «вчера» / дата — тап открывает date picker
- Сумма: большой input (`inputmode="decimal"`, `font-size: 44px`)
- Поиск категории: фильтрует список в реальном времени; если нет совпадений — кнопка ✓ добавить новую
- Заметка: появляется ТОЛЬКО после выбора категории; при выборе категории список прячется
- Долгое нажатие на категорию → кнопка «Удалить» (удаляются и дефолтные)
- Кнопка «Новая запись» — активна только при сумме > 0 И выбранной категории

### 2. Отчёты
- Карточки: Сегодня, Вчера (топ-5 записей с заметкой/категорией), Неделя, Месяц (топ-3 категории горизонтально)
- Кнопка «Новый отчёт» — добавляет карточку Год
- Тап по карточке → модальное окно с полной разбивкой по категориям

### 3. История
- Sticky-шапка: поиск (по категории и заметке) + кнопка экспорта CSV
- Записи сгруппированы по дням, отсортированы от новых
- Кнопка ✕ у каждой записи → удаление с подтверждением
- Экспорт CSV: столбцы Дата;Категория;Сумма;Заметка, UTF-8 BOM, `расходы_YYYY-MM-DD.csv`

## Категории по умолчанию (топ-10 универсальных)

## Дизайн — Espresso Color Palette
| CSS-переменная | HEX | Применение |
|---|---|---|
| `--accent` | `#5E463D` | Double Shot — кнопки, шапки, активные элементы |
| `--bg` | `#EDE7DD` | Cream — фон всех экранов |
| `--text` | `#28150F` | Текст на светлом фоне |
| `--text-inv` | `#FFFFFF` | Текст на тёмном фоне |
| `--latte` | `#DBC1A2` | Разделители, неактивные элементы |
| `--bean` | `#B69267` | Вторичный акцент, подписи |

- `width: 100%; max-width: 430px` — фиксированная ширина, центрирование на десктопе
- Шрифт: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- Суммы: целая часть — обычный размер, `,XX ₽` — 70% через класс `.dec`
- Плейсхолдеры полей ввода — `rgba(40, 21, 15, 0.7)` (70% от --text)

## Service Worker
- Текущая версия кэша: `myfinance-v6`
- Cache-first стратегия
- При смене файлов увеличивать версию (`myfinance-v7`, `v8`...)
- Для сброса кэша при разработке: DevTools → Application → Service Workers → Unregister → Ctrl+Shift+R
