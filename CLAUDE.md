# Проект: PWA трекер расходов (аналог Depoza)

## Цель
Форк Depoza (com.depoza 1.50) в виде PWA: то же поведение экранов, плюс то, чего в Depoza нет —
экспорт в CSV, рабочая автокопия в Dropbox и исправленные странности (см. ниже).
Поведение Depoza разобрано по записям экрана и декомпилированному APK.

## Стек
- Чистый HTML + CSS + JS (без фреймворков), обычные `<script>` без модулей — порядок подключения в `index.html` важен
- PWA: `manifest.json` + Service Worker (`sw.js`) — офлайн-режим; APK — обёртка TWA через PWABuilder
- Хранение данных: `localStorage`

## Модель данных (localStorage, ключ `myfinance_v1`)
```json
{
  "expenses": [{ "id": "...", "amount": 240.38, "category": "Супермаркеты", "date": "2026-03-16", "note": "Яблоки", "ts": 1773650000000 }],
  "categories": ["..."],
  "reports": [{ "id": "r1", "name": "Месяц", "pinned": false,
                "filter": { "period": { "type": "month", "offset": 0 }, "categories": null, "search": "", "mode": "categories" } }]
}
```
- `ts` — момент траты в мс; у старых записей может отсутствовать (тогда сортировка по дате)
- `mode`: `none` (только сумма) | `entries` (последние 5 записей) | `categories` (топ-3 категории)
- `period.type=custom` с `from`/`to` = `null` — без ограничения с этой стороны
- Отчёты хранятся в данных и попадают в бэкап/Dropbox

## Экраны (как в Depoza)

### Расходы
- Дата «сегодня/вчера/дата» — тап открывает календарь; для прошлой даты время траты = текущее время суток
- Сумма крупно (Light, #6E6E6E) — поле contenteditable (`makeAmountField` в ui.js), чтобы Chrome не показывал полосу автозаполнения; категории — частые в текущем месяце сверху, при равенстве по алфавиту
- Поиск категории: сначала начинающиеся с текста, потом содержащие; нет такой — ✓ создаёт
- После выбора категории список прячется, появляется «Описание»; ✕ сбрасывает категорию
- «Новая запись»: тосты «Укажите сумму» / «Укажите категорию»; после сохранения — «Запись успешно добавлена», форма очищается

### Отчёты
- Карточки из `reports`: только сумма / 5 последних записей / топ-3 категории; пустой период — «Не обнаружено записей»
- 📌 — закрепить (только один), закреплённый сверху с линейным графиком (часы / дни / месяцы)
- ⋮ — Редактировать / Удалить; «Новый отчёт» — экран с названием и фильтром
- Тап по карточке — История с фильтром отчёта

### История
- Шапка: поиск (описание и категория, без учёта регистра), итог, период «Начало / Окончание» (тап — календарь), вид Категории⇄Записи, фильтр, ⋮ «Данные»
- Тап по категории → записи этой категории + плашка «СБРОСИТЬ»; «СБРОСИТЬ» снимает фильтр, вид не меняет;
  системная «Назад» снимает фильтр и возвращает к категориям
- Свайп влево/вправо по списку — следующий/предыдущий период
- Тап по записи — диалог: дата, сумма, категория, описание, «Удалить | Сохранить»
- ⋮ «Данные»: Dropbox, Категории, Экспорт CSV, бэкап JSON, загрузка из файла

## Исправлено относительно Depoza
- «Последние 7/30 дней» включают сегодня
- Период с одной заданной границей работает (другая — без ограничения)
- Поиск без учёта регистра и для кириллицы
- Нет «1 января 1970» для пустых дат; подписи режимов по-русски
- Экспорт CSV и работающая автокопия

## Личные данные
- Репозиторий публичный: никаких трат, личных категорий и файлов экспорта в нём быть не должно
- Личные категории попадают на устройство только из данных (импорт / восстановление из Dropbox), в коде — только 10 стандартных

## Service Worker
- Текущая версия кэша: `myfinance-v12`
- Cache-first стратегия
- При смене файлов увеличивать версию (`myfinance-v7`, `v8`...)
- Для сброса кэша при разработке: DevTools → Application → Service Workers → Unregister → Ctrl+Shift+R

## APK (TWA через PWABuilder)
- Пакет `io.github.estershadow.twa`, отпечаток ключа подписи — в `.well-known/assetlinks.json`
- Пересобирать APK нужно только ради изменений оболочки (название, иконка, цвет полосы); код приложения грузится с сайта
- При пересборке: Signing key → «Use mine», тот же ключ (хранится у владельца вне проекта), иначе не встанет поверх
- **Ждёт пересборки:** установленный APK подписан как «Finance» — `short_name` в манифесте уже исправлен на «My Finance». Напомнить владельцу при следующем разговоре об APK

## Git / GitHub
- Репозиторий: https://github.com/EsterShadow/My-finance.git
- Коммиты — только по явной команде пользователя
- Папка проекта (вместе с `.git`) синхронизируется через Яндекс.Диск между ноутбуком и ПК: git (коммит, тег, Sync) запускать **только на ПК** и только после окончания синхронизации Диска; на ноутбуке — только правка файлов
- При каждом коммите обновлять `CHANGELOG.md` — только главные изменения, без мелочей
- Версии: новая запись в CHANGELOG → то же число в `APP_VERSION` (js/app.js, видно в меню ⋮ Истории) → аннотированный тег `vX.Y.Z` на коммит релиза (`git tag -a vX.Y.Z -m "..."`)
- В репозитории включено `push.followTags`: обычный push (Sync в VS Code) отправляет и теги
